# Protocol Dice Engine

**Any world. One protocol.**

Protocol Dice Engine is a setting-agnostic, classless tabletop roleplaying engine built around transparent dice pools, standalone Talents, and contemporary occult magic.

This repository publishes the **v0.005 PRE-ALPHA** playtest package.

## Open the current release

- `rules.html` — primary interactive rules guide
- `app.html` — character builder, play surface, and dice roller
- `rulebook.html` — secondary printable PDF
- `index.html` — release launch page

The two versioned HTML applications are self-contained and can also be downloaded and opened locally without a web server.

## Current rules footprint

- 52 Skills
- 24 standalone Talents
- 12 magical Practices
- 22 example Workings
- Four-die ordinary pool with a fifth die from the strongest relevant Edge
- Three starting Talents; one additional Talent every third Advancement Award

This project is independent from Protocol 7, which remains a separate game and version line.
